# Machine Learning & Deep Learning Projects

Selected academic Python/Jupyter projects covering tabular data mining, classical machine learning, convolutional neural networks, and natural-language processing.

## Projects

| Area | Notebook | Focus |
|---|---|---|
| [Data mining](data-mining/README.md) | [Exploratory analysis](data-mining/notebooks/bank-marketing-eda.ipynb) | Bank telemarketing dataset analysis, visualisation, and data-quality review |
| [Data mining](data-mining/README.md) | [Custom KNN](data-mining/notebooks/custom-knn-bank-marketing.ipynb) | Preprocessing, KNN from scratch, scikit-learn comparison, WEKA evaluation |
| [Deep learning](deep-learning/README.md) | [CIFAR-10](deep-learning/notebooks/cifar10-softmax-cnn.ipynb) | Softmax regression, CNN depth, regularization, learning rate and batch size |
| [Deep learning](deep-learning/README.md) | [IMDb sentiment](deep-learning/notebooks/imdb-rnn-lstm-birnn.ipynb) | Vanilla RNN, LSTM, bidirectional RNN, text classification |

## Getting started

Each project has its own `requirements.txt` and README. Create separate virtual environments as described there. Some notebooks download public datasets; the bank dataset must be obtained separately.

## Notes on provenance

These notebooks originate from university coursework. The source code and recorded results are preserved as submitted in the uploaded archive, except for descriptive filename changes. Before making this repository public, check collaboration credits, university academic integrity rules, and whether all included content is yours to publish.
